# Identidade de marca

O [extrato de identidade aplicado à plataforma](platform-identity.md) reúne o conceito, os princípios de linguagem e a nomenclatura disponível.

Esse extrato foi mantido como entregue. Não substitui um manual visual completo nem uma validação de domínio, registro de marca ou origem linguística. Okape e Urukum estão nomeados nas especificações funcionais, sem identidade cultural/visual completa fornecida.

Consulte o [índice geral](../README.md) e os documentos de domínio para finalidade e fronteiras de cada módulo.
