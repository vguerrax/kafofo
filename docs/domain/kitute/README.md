# Kitute — Cadernos de receitas

Status: escopo funcional do MVP aprovado; refinamentos técnicos explicitados.
Data: 2026-11-06.

Kitute é um módulo independente do Kafofo para guardar, organizar e consultar receitas em cadernos pessoais, de residência e de núcleo.
