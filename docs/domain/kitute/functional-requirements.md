# Kitute — Requisitos funcionais

| ID | Requisito |
| --- | --- |
| RF-KIT-01 | Permitir múltiplos cadernos pessoais, de residência ou de núcleo, com nome obrigatório e descrição opcional. |
| RF-KIT-02 | Definir o contexto na criação e impedir sua alteração no MVP. |
| RF-KIT-03 | Criar e consultar receitas vinculadas a exatamente um caderno. |
| RF-KIT-04 | Exigir nome, ingredientes e modo de preparo. |
| RF-KIT-05 | Permitir rendimento, tempo de preparo em minutos, observações e tags opcionais. |
| RF-KIT-06 | Preservar quebras de linha em ingredientes e permitir parágrafos/listas no modo de preparo. |
| RF-KIT-07 | Editar, excluir logicamente e restaurar receitas conforme permissão do contexto. |
| RF-KIT-08 | Administrar dados do caderno, compartilhamentos, exclusão e restauração conforme responsável definido. |
| RF-KIT-09 | Conceder e revogar acesso adicional de leitura a usuários da mesma instância, inclusive entre contextos. |
| RF-KIT-10 | Aplicar compartilhamento ao caderno inteiro, incluindo receitas adicionadas depois. |
| RF-KIT-11 | Buscar receitas pelo nome e filtrar por caderno e tags, sem expor conteúdo não autorizado. |
| RF-KIT-12 | Registrar e exibir criador, último editor e respectivas datas da receita. |
| RF-KIT-13 | Detectar conflito de edição, avisar e preservar o texto ainda não salvo, sem sobrescrita silenciosa. |
| RF-KIT-14 | Excluir logicamente e recuperar cadernos respeitando o ciclo de vida definido. |
| RF-KIT-15 | Revogar acesso decorrente do contexto na saída ou remoção do membro, preservando receitas compartilhadas e autoria. |
| RF-KIT-16 | Compartilhar tags no contexto, seguindo o padrão do Urukum. |
