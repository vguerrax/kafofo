# Arakatu — Requisitos funcionais

**Escopo dos IDs:** `arakatu`. São 15 títulos do levantamento consolidado, preservados. A coluna de detalhamento sintetiza as capacidades textuais da mesma seção; não cria regras para campos ou fluxos ausentes.

| ID | Título original | Detalhamento sustentado pela fonte |
| --- | --- | --- |
| RF-124 | Calendário integrado | Calendário utilizável dentro do Kafofo, com criação e administração de eventos. |
| RF-125 | Integração de eventos | Integrar informações de eventos de diferentes origens, conforme contratos a detalhar. |
| RF-126 | Agenda pessoal | Disponibilizar agenda pessoal. |
| RF-127 | Agenda compartilhada | Disponibilizar agenda compartilhada em contextos autorizados. |
| RF-128 | Integração com calendários externos | Integrar calendários externos sem impor migração de serviços. |
| RF-129 | Importação e exportação iCalendar | Permitir importação e exportação iCalendar; operação concreta e abrangência pendentes. |
| RF-130 | Visualização consolidada | Visualizar eventos de diferentes origens de forma consolidada, identificando origem. |
| RF-131 | Sincronização unidirecional | Manter sincronização unidirecional no MVP; direção de cada fluxo a especificar. |
| RF-132 | Recorrência de eventos | Disponibilizar eventos recorrentes, com tratamento de exceções. |
| RF-133 | Frequências de recorrência | Frequências diária, semanal, mensal e anual. |
| RF-134 | Edição de recorrência | Editar uma ocorrência específica ou toda série, preservando demais ocorrências no caso isolado. |
| RF-135 | Exclusão de recorrência | Excluir uma ocorrência específica ou toda série; ciclo de recuperação a detalhar. |
| RF-136 | Lembretes de eventos | Disponibilizar lembretes de eventos pelo centro de notificações. |
| RF-137 | Múltiplos lembretes | Permitir múltiplos lembretes por evento. |
| RF-138 | Antecedência configurável | Permitir configurar antecedências, respeitando preferências individuais. |
