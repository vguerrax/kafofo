# Planejamento das entregas

O planejamento executável é mantido no GitHub:

- [Alpha 1 — Compras compartilhadas: escopo, decisões e aceitação](https://github.com/vguerrax/kafofo/issues/1).
- [Issues do repositório](https://github.com/vguerrax/kafofo/issues).
- [Configuração do Project](https://github.com/vguerrax/kafofo/issues/2).
- [Refinamentos necessários antes da implementação](https://github.com/vguerrax/kafofo/issues/3).

A Alpha 1 é um recorte do MVP, com listas somente de residência. As decisões de escopo e os critérios de conclusão estão na issue de referência; não são copiados para uma segunda lista local. Documentação de módulos futuros, incluindo Kitute, não implica inclusão nesta entrega.

Quando refinamentos forem incorporados aos documentos de domínio, manter referência à decisão e seu alcance. Não resolver silenciosamente pendências históricas nem tratar resultado documental como implementação.

## Contratos aprovados

O comportamento aprovado está nos contratos da [plataforma](../domain/platform/alpha-1.md) e do [Kitanda](../domain/kitanda/alpha-1.md). O backlog mantém tarefas e evidências, sem uma lista de status paralela neste diretório.
