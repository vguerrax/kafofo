# ADR-0004: Frontend com React, TypeScript e Vite

- **Status:** Aceita
- **Data de registro:** 2026-11-03
- **Projeto:** Kafofo

## Contexto

A interface deve atender uso pessoal e compartilhado em dispositivos de tamanhos diferentes.

## Decisão

Usar React com TypeScript e Vite, em uma aplicação única com interface web responsiva.

## Consequências e riscos

Permite organização por funcionalidades e evolução da experiência. Traz a necessidade de administrar estado, carregamento, acessibilidade e erros de comunicação.

## Alternativas de referência

Renderização de páginas no backend; aplicações frontend separadas por módulo.

## Validação e pontos em aberto

Bibliotecas visuais, de formulários e de estado não estão implicitamente aprovadas por esta decisão; ver ADR-0020.
